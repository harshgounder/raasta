## Mind-boggling demo angles (3)
- Human versus detector: a browser plays consented genuine and cloned 2–10 second clips and asks the judge to guess before revealing the detector score. A Python backend runs AASIST-L and optionally the SSL model; present scores as evidence, not proof of authenticity.
- Phone-line stress test: browser audio controls add bandwidth restriction and noise to the same clip, then send each version to the inference backend. Display where the verdict changes, making robustness—or its failure—immediately visible.
- Unknown-cloner showdown: the browser reveals results on held-out cloning tools and In-the-Wild examples while a duration slider reduces available speech from ten seconds to two. Backend evaluation compares both detectors against fixed thresholds and displays an uncertain outcome when evidence is insufficient; this is a proposed evaluation feature, not an existing demonstrated capability.

## Risks (3)
- Generalization and false reassurance: ASVspoof performance does not establish reliability on unseen cloning tools, two-second excerpts or telephone channels. ASVspoof 2019 explicitly lacks telephone/mobile codecs; synthetic speech is also not synonymous with a scam, and a genuine voice does not establish a legitimate caller.
- Deployment and privacy: the supplied evaluators are not turnkey browser applications, AASIST's main script rejects CPU execution, and the SSL checkpoint is 1.18 GB. Measure CPU latency and memory before promising responsiveness, and avoid retaining sensitive uploaded conversations.
- Licensing uncertainty: the repositories are MIT-licensed, but separate terms for externally hosted SSL weights were not established and the ASVspoof dataset license was not recovered. In-the-Wild has conflicting declarations: Apache-2.0 on the project page versus CC-BY-SA-4.0 on Hugging Face; resolve these before redistribution or commercial use.

## Missing pieces (3)
- For the shortlisted repositories, a polished recording/upload interface and a tested single-clip CPU service still need to be built; the supplied entry points primarily evaluate dataset files.
- No verified browser-native checkpoint/runtime was established for these candidates. Fully local execution would require export, operator-compatibility checks and browser performance testing rather than merely loading the PyTorch checkpoint.
- A reproducible short-clip, unseen-generator evaluation and calibrated decision policy are missing: test 2–10 second excerpts on ASVspoof 2019 LA and In-the-Wild, add held-out cloning tools and telephone-channel transformations, and avoid silently treating repeated two-second audio as four seconds of independent evidence.
