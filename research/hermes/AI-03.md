- **arXiv API**: dense. 5 of the 5 queries returned on-topic construction and GraphRAG papers, most 2026-dated. Two papers had public code links in the abstract or abs page (ReTAG, AutoSchemaKG). Most new 2026 papers have no repo yet, so they fail the "code or demo exists" rule and are not in the table.
- **GitHub API**: 32 repos, exact star and pushed_at values, 2026-10-24.
- **Devpost**: Hypermode Knowledge Graph + AI Challenge gallery (45 projects, winner list visible), plus snippets from ArangoDB hackathon, JacHacks, FullyHacks, W&B Judgement Day.

- **Qiita / Zenn (Japan)**: 9 GraphRAG articles returned, mostly tutorials on Microsoft GraphRAG with Neo4j. None shipped a standalone tool, so only the two with numbers worth reusing are summarized in notes.
- **Korean sources**: velog/Tistory articles on GraphRAG, plus the AWS Korea GraphRAG Toolkit post. No Korean-built KG builder surfaced beyond AutoRAG (which is RAG, not KG) and the GraphRAG Toolkit sample.
- **Chinese sources**: Zhihu, cnblogs, Tencent Cloud, CSDN, leiphone. Found Ant Group KAG, Tencent Youtu-GraphRAG, a 6-project GraphRAG ecosystem roundup on cnblogs.
- **Hugging Face**: model cards for HHEM, MiniCheck, Bonito (used in AI-04); Space search for KG demos returned cookbook notebooks, not standalone demos.

- **Zhihu** article on a Chinese GraphRAG walkthrough appeared in search but was not opened; login wall risk. Not counted as a verified row.
- **`microsoft/graphrag-accelerator` and `whyhow-ai/knowledge-graph-studio` both return 404** from the GitHub API on 2026-10-24. If a plan depends on either, it is gone or private.
- **`stair-lab/KGGen` 404.** The KGGen paper is real (OpenReview id YyhRJXxbpi) but the repo path in the paper's citation did not resolve under that owner. Not in the table because the code could not be confirmed.
- **`docs2kg/docs2kg` 404** on the GitHub API on 2026-10-24 even though the arXiv paper (2406.02962) describes an open-source framework. Code not located, so the paper is excluded per the "code or demo exists" rule.
- **Star discrepancy on graphify**: repo page shows 57.9k, GitHub API returned 134,047 for the same slug minutes apart. Use the page number in any pitch and do not quote either as a growth claim.
- **Demo track gap**: no 2025/2026 ACL, EMNLP, SIGIR or NeurIPS demo paper shipped a public hosted KG builder that survived a fetch. The runnable demos in this space are product demos (Neo4j Labs, OpenSPG) and static-site tools (GraphRAG Visualizer, graphify output), not paper demos.
- **Regional gap**: Japanese and Korean posts are almost all tutorials over Microsoft GraphRAG or LightRAG, not original builders. The original work in this space is concentrated in China (Ant, Tencent, ZJU, HKUST, Alibaba) plus EU/US startups.
