## 3_the_product_angle_a_molecule_courtroom_not_another_calculator

### 3.1 Proposed Case Study: The Salt That Changes The Answer

Start with a molecular input containing more than one component. The user sees the original drawing and an explicit question: **"Analyze the submitted form, or analyze the selected parent?"** A proposed parent appears alongside it, with the removed component highlighted rather than disappearing.

This is a realistic composition target because ChEMBL Structure Pipeline documents standardization, salt stripping, and parent retrieval; Indigo separately documents ChemDiff and depiction tools. Their existence supports an inspectable transformation workflow, although the proposed combined interface itself has not been built or benchmarked here. Confidence in source capabilities: high; integration feasibility: medium. [3_the_product_angle_a_molecule_courtroom_not_another_calculator[0]] [10][3_the_product_angle_a_molecule_courtroom_not_another_calculator[1]] [8]

The important outcome is not a scientifically dramatic property change. It is that the application refuses to conceal a change in what was analyzed. The judge should understand the distinction without knowing molecular notation: "You submitted this; we can compare it with that; these are not silently interchangeable."

**Decision:** Make the original submitted representation immutable. Treat standardization, parent selection, charge handling, and tautomer policy as separate, named steps. Show intermediate structures and attach the selected policy to every computed result.

| Proposed result state | Precise product meaning | Example presentation |

## 4_frozen_evidence_and_replay_what_can_honestly_be_promised

### 4.1 Proposed Case Study: Unplug, Reopen, And Explain The Same Result

The judge clicks "Freeze run," downloads an evidence package, disables connectivity, and reopens it. The application restores the original molecule, selected policy, values, evidence statuses, and provenance receipt. It labels this **archived replay**.

DVC documents versioning and pipeline comparison; ro-crate-py documents adding files and contextual entities and exporting a directory or ZIP. Those capabilities support packaging and tracking, but an exported crate is not automatically an executable, bit-for-bit reproducible chemistry environment. Confidence: high. [4_frozen_evidence_and_replay_what_can_honestly_be_promised[0]] [17][4_frozen_evidence_and_replay_what_can_honestly_be_promised[1]] [16]

The non-obvious distinction is between **replaying preserved outputs** and **recomputing them on another machine**. The first can be deterministic by construction. The second must be demonstrated for the supported environment and operation set; it should not be promised merely because a random seed or package version was saved.

**Decision:** Present two buttons: "Open archived result" and "Recompute and compare." If recomputation differs, show the difference instead of overwriting the archive.

| Proposed run-capsule artifact | Why it is needed | Existing component role |
|---|---|---|
| Original input bytes and format | Preserve what was actually submitted | Wrapper-owned artifact |

## 6_ten_judge_what_ifs_with_honest_answers

| Judge question | Honest answer | Demo move |
|---|---|---|
| **1. What if the input is wrong?** | Parsing and chemical validation are separate failure stages. Exact diagnostics depend on the pinned engine and supported format. | Use a reviewed malformed-input fixture and a separately reviewed valence-error fixture; show distinct categories. |
| **2. What if someone tries to attack it?** | Chemical validity is not application security. Inputs still need size limits, escaping, timeouts and isolation. These are proposed safeguards, not a verified security certification. | Submit a long or hostile-looking text fixture; show safe rejection without executing or rendering it as markup. |
| **3. What if I type in Hindi?** | A Hindi interface can be localized. Arbitrary Hindi chemical-name resolution was not verified. | Preserve the original text; offer a curated alias only if present, then require structure confirmation. Otherwise say unsupported name resolution. |
| **4. What if there is no internet?** | Bundled chemistry operations and saved evidence can be designed to work offline. New remote lookup cannot. | Disconnect and replay a frozen fixture; show a disabled live-lookup control. |
| **5. What if it is a photo of a screen?** | Molecular OCR is a discovered lead, not a verified laptop-ready component here. Recognition must not bypass validation. | In the core demo, request drawing/text. If OCR is later verified, show recognized structure as a draft requiring confirmation. |
| **6. What if the stereochemistry is missing?** | Missing stereochemistry is not automatically an invalid molecule, but may leave identity unresolved. | Show an ambiguity badge and block an identity-sensitive comparison until the user chooses a policy. |
| **7. What if it is a salt or charged form?** | The submitted form and a selected parent must remain distinguishable. | Toggle between them without deleting the original; show which properties belong to which representation. |
| **8. What if another tautomer is possible?** | Results depend on the declared tautomer policy; the application should not imply that one canonical representation is a measured population. | Show the policy and a small alternatives grid, with the selected form clearly identified. |
| **9. What if PubChem or ChEMBL has no value?** | Absence in the selected snapshot is not a zero and not proof of global absence. | Open a not-available card that names the searched snapshot and field. |
| **10. What if another computer gives a different answer?** | Archived output replay and fresh computation are different promises. Recompute must compare against the preserved run. | Open the archived package, then show a comparison panel for a separately executed run; retain any mismatch. |

**Takeaway:** Every answer preserves a boundary. The interface should make those boundaries feel deliberate, not like unexplained failures.

The most effective proposed judge case is Hindi input: the app keeps the original words, admits when name resolution is unsupported, and asks the person to confirm a structure rather than inventing one. That is a stronger evidence story than an unverified multilingual chatbot pretending to understand every chemical name.

Three tensions should drive the final design. First, **standardization improves consistency but can conceal identity changes**; show the changes. Second, **more data can improve coverage but undermine reproducibility if retrieved live**; freeze the evidence actually used. Third, **more impressive visuals can create unjustified confidence**; connect every visualization to the selected representation and label generated geometry as such.
